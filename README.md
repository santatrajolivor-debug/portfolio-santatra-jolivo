## 🌐 Lancer le portfolio

### Option 1 — Ouvrir directement (recommandé pour test rapide)
Double-cliquez sur `index.html` pour l'ouvrir dans votre navigateur.

### Option 2 — Serveur local (recommandé pour la production)
Si vous avez Python installé :
```bash
cd D:\portfolio-santatra-jolivo
python -m http.server 8080
```
Puis ouvrez : http://localhost:8080

Ou avec XAMPP, placez le dossier dans `htdocs` et accédez via : http://localhost/portfolio-santatra-jolivo/

## 🎨 Personnalisation

Le fichier `assets/css/style.css` contient toutes les variables de couleur dans `:root` :

```css
:root {
    --accent: #00d4ff;      /* Couleur principale (cyan/bleu électrique) */
    --purple: #7c3aed;      /* Couleur secondaire (violet) */
    --bg-primary: #0a0a0f;  /* Fond principal (noir profond) */
}
```
